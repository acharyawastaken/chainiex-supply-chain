# ChaiNIEx — Requirements

## Runtime Dependencies (Node.js)
- express ^4.21.0          # Web framework
- pg ^8.13.0               # PostgreSQL driver (node-postgres)
- jsonwebtoken ^9.0.2      # JWT authentication
- bcryptjs ^2.4.3          # Password hashing (bcrypt)
- cors ^2.8.5              # Cross-origin resource sharing
- dotenv ^16.4.5           # Environment variable loading

## Dev Dependencies
- nodemon ^3.1.4           # Auto-restart on file changes

## System Requirements
- Node.js >= 20 LTS
- PostgreSQL >= 16.x
- npm >= 10

## Database Tools
- pgAdmin 4 — for visual PostgreSQL database management
- Postman — for API testing

## Quick Install
```bash
cd api
npm install
```
